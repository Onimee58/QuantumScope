# QuantumScope v0.3.0 — Canvas navigation and terminal measurement

## Circuit navigation

- **Middle-click and drag** the circuit canvas to pan.
- **Shift + left-drag** to pan without placing gates.
- **Ctrl + mouse wheel** to zoom the qubit-wire layout.
- Use **+ Zoom**, **− Zoom**, or **Fit Circuit** above the canvas.
- Click a circuit-column header to inspect that step. Compact previous/play/next and step controls are retained because quantum-state evolution inspection differs from measurement.

## Measurement gate (M)

Select or drag **M** from the palette and place it on one or more qubit wires in the **same terminal circuit column**. The gate is a measurement annotation, not an ideal unitary operation. Unitarians may not follow terminal measurements, and the editor rejects unsupported placements. Measurement results report the joint sampled bitstrings for only the wires with M, while the existing probability display remains a full-state preview. If there are no M markers, the legacy Measure All button still provides all-qubit samples.

### Interchange

- `.qscope` files save the terminal measurement indices in a backward-compatible optional `terminal_measurements` JSON key.
- OpenQASM 2 exports matching `creg c[n]; measure q[i] -> c[i];` statements.
- The importer and QASM converter accept terminal measurements using **matching qubit/classical indexes**, and reject mid-circuit measurement, conditional gates, and arbitrary classical mapping rather than silently dropping them.
- State evolution is ideal-statevector only; this build does not simulate device readout noise or classical feed-forward.

## Known limitations / testing

The circuit still uses the Qt table-backed graphical grid. It now supports panning and zooming, but a dedicated scene-graph editor could be a later architectural improvement. The test suite validates terminal measurement data interoperability; desktop mouse interaction still requires local Qt testing on Windows and Ubuntu before release.
