# QuantumScope v0.3.0 — GUI finishing pass

This candidate preserves the simulation and file-conversion code from the previous v0.3.0 verification build.

## GUI changes

- Circuit editing surface now renders horizontal quantum wires, standard control dots, target symbols, swap crosses, and boxed single-qubit gates. The existing table-model interaction, step navigation, save formats, and gate semantics remain intact.
- Gate palette uses larger selectable gate tiles with clearer hover and selection states.
- Circuit wire rows and columns have more breathing room, without scaling gate text disproportionately when resizing.
- About screen has a new branded presentation, current project coverage, developer credits, and direct GitHub/SMU links.
- Developer GitHub avatar is loaded from the public GitHub avatar CDN URL and cached under the Qt user cache location. On a first offline launch, the avatar placeholder is shown until a successful online load; no local image upload is required.

## Validation

- Python source compiles.
- 74 existing tests pass.
- PySide6 GUI runtime verification must be completed on Windows or Linux with application dependencies installed.

## Suggested local acceptance check

1. Open Quantum Circuits; place H, CX, CCX and CSWAP, ensuring the correct control/target glyphs appear and click-to-place / drag/drop remain functional.
2. Change the qubit count; inspect wires and Bloch sphere alignment at several window sizes.
3. Try the Bell and arithmetic examples and compare probability plots and verification results with the previous candidate.
4. Open About while online; close and reopen while offline to confirm avatar caching.
5. Verify Linux `.deb` and Windows setup builds in GitHub Actions before releasing.

No new physics features were intentionally added in this UI pass.
