# QuantumScope v0.4.0 – GUI refinement test build

Development baseline: previous v0.4.0 circuit editor source ZIP. This is a local test candidate, not a verified release.

## Included changes

- Existing gates can be dragged within circuit columns or to a new column. Multiqubit operations move as one unit and retain operand offsets. Invalid destinations leave operations unchanged.
- Dragging a multi-qubit gate from the palette starts operand selection: click its second (and third) qubit in the same column. Press Esc or right click during placement to cancel.
- Double-click on a placed parameterized gate edits parameters. Double-clicking a nonparameterized placed gate does nothing. Gate Explorer documentation opens by double-clicking palette entries only.
- Right-click a column header to insert before/after, or delete an empty column. Explicitly inserted empty columns are retained until removed.
- Theme-aware palette, circuit table, output text, verification tables, dialogs, and histogram text. Existing dark theme remains default.

## Local GUI test checklist

1. In Dark and Light mode, test histogram axis/legend, truth table, Results pane, tab labels, palette selection, Gate Explorer and PDF export.
2. Drag H from left palette; drag it to another empty cell. Undo and Redo.
3. Drag CX from palette to q0. Click q1 in the *same column*. Check connected operation. Move CX by dragging one symbol to another column. Undo.
4. Drag CCX to first control, click second control and target. Press Esc to cancel any partially selected gate.
5. Right-click header of occupied column, insert before/after, confirm all gates shifted without changing their parameters; undo/redo.
6. Double-click placed H (nothing). Double-click placed RX (edit parameter). Double-click palette H (documentation).
7. Save/load native file, import/export QASM, and check measurement-specific histograms.
8. Check behavior on Windows and Ubuntu with OS Light and Dark system appearances.

## Test limitations

Python unit tests and compilation are run in a headless environment without PySide6. Desktop interaction, Windows installer, and .deb packaging require local validation. This build should not replace the public release before GUI testing.
