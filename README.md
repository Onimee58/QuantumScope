# QuantumScope

**Interactive quantum mechanics, quantum circuits and quantum machine learning, for teaching and learning.**

**[Download the latest release](https://github.com/Onimee58/QuantumScope/releases/latest)**

</div>

This repository publishes QuantumScope's **installers and release notes**. The source code is developed privately.

## Install

Open the **[latest release](https://github.com/Onimee58/QuantumScope/releases/latest)** and download the installer for your computer:

| System | File |
|---|---|
| Windows 10 or 11 (64-bit) | `QuantumScope-<version>-Setup.exe` |
| macOS (Apple Silicon) | `QuantumScope-<version>-macOS.dmg` |
| Ubuntu or Debian (64-bit) | `quantumscope_<version>_amd64.deb` |

Each installer has a `.sha256` file beside it to check the download. The **user guide** (PDF) is attached to every release.

## Updates

QuantumScope can check for updates itself: **About → Check for updates**. It asks before connecting to the internet, and verifies every download.

## Problems and suggestions

Please **[open an issue](https://github.com/Onimee58/QuantumScope/issues)**: say what you did, what happened, your system, and attach a screenshot if you can.
