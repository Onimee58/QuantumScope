# QuantumScope v0.3.0 – demo candidate

## Workspaces
- **Hydrogen:** Explorer opens by default; add Dynamics 2D/3D using its own + menu.
- **Quantum Principles:** Double Slit opens by default; its + menu offers Double Slit, Superposition, and Entanglement.
- **Quantum Circuits:** Circuit Editor and QASM Converter; the + menu lists these tools only.

## Circuit editing
- 1–10 qubit ideal statevector simulator; no hardware execution or noise.
- Drag gate names from the palette or select a gate and click a circuit cell; two-qubit gates use the second-qubit field.
- Bloch glyphs appear next to each qubit wire, with local Bloch-vector lengths shrinking under entanglement.
- Step slider updates local reduced states. Probability bars show theoretical outcome probabilities and, after Measure, shot frequencies.
- Adding qubits preserves gates; decreasing the count warns before deleting operations targeting removed wires.
- Undo and Redo preserve editing snapshots.

## Circuit interchange
The `.qscope` format is a JSON document with `format`, `schema_version`, `qubits`, and ordered `operations`.
The QASM Converter provides bidirectional conversion for this deliberately restricted **OpenQASM 2.0 subset**:
H, X, Y, Z, S, T, RX, RY, RZ, CX, CZ, SWAP, and nonoperative barriers.
Only one quantum register is supported. Import rejects measurements, classical registers, conditionals, custom gate definitions, and unknown operations. Export preserves supported unitary operations and numerical rotation angles, **not** application-specific visual settings. For circuits containing measurements, use a supported external QASM tool instead. QASM 3 is not supported yet.

## Recommended demonstration
1. Build `H q0; CX q0,q1`, inspect steps and reduced Bloch vectors.
2. Measure many shots and compare experimental vs theoretical probability bars.
3. Save `.qscope`, export QASM, and import the QASM again in the Converter.
4. Add qubits and confirm the original gates remain.
5. Switch between workspaces and use each local + menu.
