# QuantumScope v0.4.0 — Circuit editor enhancements

- Drag/drop and original v0.3.0 editor functionality preserved.
- Double-click a placed parameterized gate to edit angles in radians (pi/2, -pi/4, 2*pi). Use right-click for edit, information, and remove.
- Changes participate in Undo/Redo and native/QASM exports via existing gate model.
- Double-click palette items to open Gate Explorer with explanations, single-qubit matrices, basis transformations and adjustable angle examples.
- Export PDF for vector circuit diagrams; optionally include final state probabilities.
- No simulator redesign; existing 10-qubit limit retained.

## Remaining considerations
- Light-theme colors are inherited from v0.3.0 and remain an identified issue.
- Dedicated animated Bloch demonstrations and extensive externally referenced learning materials are future Gate Explorer extensions.
- Qt GUI and installer functionality require local testing; this environment does not have PySide6 installed.
