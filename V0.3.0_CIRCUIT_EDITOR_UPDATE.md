# QuantumScope 0.3.0 — Circuit editor development candidate

## Changes

- Drag gates from the palette onto qubit cells. You may alternatively select a palette item and click a cell. Dropping near the edge grows the number of editor columns by ten, up to 500 displayed columns.
- Simulation scrubbing is **column-based**, rather than gate-based. Each occupied column applies its non-overlapping gates as a layer. Click a column header to jump to its state, or use the previous/next/play buttons and speed control. The current circuit column is highlighted; long circuits scroll horizontally.
- Inline reduced-state Bloch views show each qubit and are synchronized with circuit layers. An entangled qubit can have a Bloch vector of length less than one.
- Compact vertical measurement histogram compares exact probabilities with sampled outcomes, for up to ten most probable outcomes.
- Up to ten qubits for the ideal statevector simulation. This is not a ten-gate limit. Input operations may occupy up to 500 displayed columns.
- Added U (OpenQASM `u3`), P, SX, S-dagger, T-dagger, CCX / Toffoli, and CSWAP / Fredkin to simulation and conversion. U parameters are specified in degrees in the editor and converted to radians in circuit files.
- Gate examples include Bell, GHZ, half adder, half subtractor, and a reversible 2-bit adder with carry work qubits. Example circuits initialize their input registers with X gates.
- `.qasm`, `.qasm2` accept OpenQASM 2 syntax; `.qscope` is the versioned native circuit format. Save dialogs suggest filenames and append an extension when omitted.
- The `.qscope` interchange format preserves gate sequence and parameters. Column positions and other editor metadata are **not round-tripped** through OpenQASM 2.

## Known limitations

- OpenQASM 2 **subset only**: measurement statements, conditional operations, arbitrary declared gates, and classical registers are deliberately rejected. Do not import QASM 3 through the QASM 2 importer.
- Gates in separate positions are serialized sequentially; no parallelism metadata is promised on a QASM round trip.
- The palette uses basic text tiles rather than custom illustrated gate glyphs. Multi-qubit connections are labeled with target indices, but not yet drawn as connected gate wires. This remains a planned visual upgrade.
- The circuit editor is still table-based; drag and drop requires validation on Ubuntu/Windows, and the GUI was not launched in the build environment because PySide6 is unavailable.
- Gate examples are **reversible classical arithmetic** demonstrations acting on computational-basis input states. They are not optimized arithmetic oracles.

## Suggested acceptance test

1. Launch the editor; drag an `H` onto `q0` in column 1, then a `CX` onto `q0` in column 2 with target `q1`.
2. Click the first/second column header or use the timeline; observe local Bloch vectors become mixed after CX and a 50/50 probability histogram for `00`/`11`.
3. Increase the qubit count; gates should remain. Place a gate into column 10; observe automatic expansion. Check Undo/Redo.
4. Load the half-adder example, change example choice to half subtractor, and verify result probabilities.
5. Save as `.qscope`; export to `.qasm2`; import `.qasm2` and compare circuit operations.
6. Resize the window and verify scroll bars activate without stretched labels.
