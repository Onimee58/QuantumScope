# QuantumScope v0.4.0 release candidate

This build includes the previously tested v0.4.0 editor work, plus the following targeted fixes:

- Circuit cells no longer launch Qt's native text editor by double-clicking an empty cell; parameterized gates continue to use the dedicated parameter editor.
- Fit Circuit now limits how small circuit columns and rows become so long circuits remain readable. Very long circuits will need panning instead of fitting every column onscreen at once.
- A **Reset Zoom** button restores standard operation cell sizes.
- GitHub Actions release workflow now includes a macOS runner, producing `QuantumScope-0.4.0-macOS.dmg` (an unsigned `.app` inside the disk image) in addition to Windows and Debian installers.

## Before GitHub release

1. Test GUI on Ubuntu/Windows: empty-cell double click, gate parameter editor, Fit Circuit, Reset Zoom, zoom/pan, and long circuits.
2. Push branch to GitHub and run **Build installable QuantumScope releases** via `workflow_dispatch`; confirm macOS job succeeds and download its artifact. A macOS binary cannot be built or tested by this Linux-only environment.
3. Test the downloaded DMG on a real Mac before making the release public. For unsigned software, macOS Gatekeeper may warn; use Control-click -> Open if allowed by your organization's security policy.
4. Test Linux and Windows release artifacts before attaching them to the GitHub release.
5. Do not assume Apple notarization or code-signing is present. This job builds an unsigned DMG; automated signing/notarization can be added later.
